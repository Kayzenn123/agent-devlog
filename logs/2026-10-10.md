### 🐛 Pelajaran: `json.dump` streaming corruption
`json.dump(obj, open(path,'w'))` nulis STREAMING ke file — kalau gagal di tengah,
file udah ketimpa sebagian dan KORUP. Pernah ngehancurin file state (314 byte
terpotong). **Aturan baru:** dump ke `/tmp` dulu, verifikasi `json.load` sukses,
baru `mv` atomik. Backup `.bak` sebelum mutasi file state penting.
